2. CLIENT ADMIN PORTAL
-----------------------------------------------
URL: http://localhost:5173/login/admin
Client Admin accounts are NOT pre-created.
They are provisioned by the Super Admin.

To test the full flow:
  1. Login as Super Admin (see above)
  2. Go to Organizations → Create Organization
  3. Fill in details and a Client Admin email
  4. Copy the one-time temporary password displayed
  5. Logout of Super Admin
  6. Go to Client Admin login (URL above)
  7. Enter the email + temporary password
  8. You will be forced to change the password
  9. Complete the onboarding wizard

3. CUSTOMER PORTAL
-----------------------------------------------
URL: http://localhost:5173/login/user
Customer accounts are self-registered via the signup form.

===============================================
PORTAL SECURITY
===============================================
- Super Admin can ONLY access /super-admin/* portal
- Client Admin can ONLY access /admin/* portal
- Customers can ONLY access /customer/* portal
- Cross-portal access is blocked at both the
  login page and route-guard level
